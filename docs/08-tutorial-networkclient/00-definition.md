# Definition

------------

**Version**: 5.6
**Date**: February-2026

------------

A **network client** represents a customer or service endpoint that is connected to the fiber-optic infrastructure and consumes one or more network services. It defines the point where the physical network is delivered to an end user, building, or organization and is associated with the network elements that provide the connection.

This section describes how network clients are created, located on the map, and linked to the physical infrastructure, such as access points, buildings, and distribution nodes. It also explains how client connections are represented within the network topology and how the tool supports common operational tasks such as service provisioning, connection updates, and basic analysis of client coverage and availability.
