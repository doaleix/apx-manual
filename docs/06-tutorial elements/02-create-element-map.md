# Create new element (Map)

This guide will help you create an **Element** using the **Map**.

## **Prerequisites**
1.	**User ID** and **Password** to access APXGIS programme.

------------

**Version**: 5.5
**Date**: December-2025

------------
## **Step by Step**

The best practice is to select the project and the layer in wich the element will be set.

Repeat Steps 1 through 4 from previous <u>[document](01-create-element-menu.md)</u>

5\. Move the cursor and place it on the desire location on the map and right-click over it.

![](/img/downloads/02-create-element-map_5.jpeg)


6\. The "**element selection**"  window  will open. This window has all the elements available to add from the map. For this example "**Chamber**" was selected.

![](/img/downloads/02-create-element-map_6.jpeg)


7\. The "**element information**" window will be opened. From here you have to fill in the information as in previous section steps 8 through 10.

**Outcome:** The element was created from **Map**.
