# Create new element (Operations menu)

This guide will help you create an **Element** using **Operations** menu.

## **Prerequisites**
1.	**User ID** and **Password** to access APXGIS programme.

------------

**Version**: 5.5
**Date**: December 2025

------------
## **Step by Step**

The best practice is to select the project and the layer in wich the element will be set.

1\. Click "**Select Project**" dropdown.

![](/img/downloads/01-create_element-menu_1.jpeg)


2\. Select the **Project** where the element will belong. For this example "**north-project**" was selected.

![](/img/downloads/01-create_element-menu_2.jpeg)

**Note**: If the element should belong to more than one project, it can be added afterwards.

3\. Click the "**Visualization Menu**" located at the top right area of the map, in order to select the layer.

![](/img/downloads/01-create_element-menu_3.jpeg)


4\. Select the layer. For this example "**north-design**" layer was selected.

![](/img/downloads/01-create_element-menu_4.jpeg)


5\. Click "**Operations**" option.

![](/img/downloads/01-create_element-menu_5.jpeg)


6\. Click on the option that refers to the element type you want to set. For this example "**New Chamber**" was selected.

![](/img/downloads/01-create_element-menu_6.jpeg)


7\. The programme will send a message at the top of the map asking for a location. Move the cursor and place it on the desired location on the map and do a left-click.

![](/img/downloads/01-create_element-menu_7.jpeg)


8\. The element information window will open. From here you have to fill in the basic information of the element to be created.

Type in the description of the element, for this example "**north chamber 006**" was typed.

![](/img/downloads/01-create_element-menu_8.jpeg)


9\. Click "**Layer**" field and select the layer. For this example "**north-design**" layer was selected.

![](/img/downloads/01-create_element-menu_9.jpeg)


10\. Click "**Apply**" button.

![](/img/downloads/01-create_element-menu_10.jpeg)


**Outcome:** The element was created from Operations menu.
